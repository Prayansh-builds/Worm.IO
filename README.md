# Glow Worm APK (free, built by GitHub)

1. Make a free account at github.com and create a new repository (any name, set it to Public).
2. Click "uploading an existing file" and drag in EVERYTHING from this folder.
   Make sure the hidden .github folder is included (on a phone, use a computer for this step).
3. Open the "Actions" tab. A run called "Build APK" starts by itself (about 5 minutes).
   If it does not start, open "Build APK" and press "Run workflow".
4. When it turns green, open the run and download "glow-worm-apk" at the bottom.
   Unzip it to get app-debug.apk.
5. Send the APK to your phone and open it. Android will ask you to allow installs
   from this source. Allow it once.

Notes
- The app plays offline. Multiplayer lobbies and the online leaderboard only work inside claude.ai.
- This is a debug build. For the Play Store you need a signed release build and a Google developer account.
